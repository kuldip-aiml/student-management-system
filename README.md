# Student Management System

## Description

A menu-driven Student Management System built using Python. It allows users to add, search, update, delete, and manage student records.

## Features

- Add new students
- Search students
- Update student marks
- Delete students
- Show student statistics
- Show above-average students
- Show pass and fail students
- Count pass and fail students
- Get students by grade
- Save student data using JSON

## Technologies Used

- Python
- JSON
- Functions
- Exception Handling
- Lambda, Filter and Reduce
- Modular Programming

## How to Run

1. Clone the repository.
2. Open the project folder in VS Code.
3. Run `main.py`.
